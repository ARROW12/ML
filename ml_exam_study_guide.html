1. ML Fundamentals

Understanding Tasks, Experience, Performance, and Learning Types.

👨‍🏫 Teacher's Insight

Examiners almost always start with a conceptual question. You must know Tom Mitchell's definition perfectly: "A computer program is said to learn from experience E with respect to some task T and some performance measure P, if its performance on T, as measured by P, improves with experience E." You also need to classify problems into Supervised, Unsupervised, or Reinforcement Learning.

📝 Predicted Question

High Probability

Part A: An online retail platform wants to predict whether a product review is "positive", "negative", or "neutral" using a large set of previously labeled customer reviews. Identify the type of learning (Supervised, Unsupervised, or Reinforcement) and justify.

Part B: Suppose you provide a learning algorithm with historical weather data to predict if tomorrow will be Sunny, Windy, or Rainy. In this setting, define E, T, and P. Name two possible performance measures.

✅ Solution Walkthrough

Part A Answer:

Type: Supervised Learning.

Justification: The problem explicitly states that the algorithm learns from a dataset of "previously labeled" customer reviews. Because the target outputs (labels: positive, negative, neutral) are provided during training to guide the algorithm, it falls strictly under supervised learning.

Part B Answer:

  • Task (T): Predicting tomorrow's weather condition (Sunny, Windy, Rainy). This is a classification task.
  • Experience (E): The historical weather data provided to the algorithm.
  • Performance (P): The accuracy of the predictions.

Two Possible Performance Measures:

  1. The percentage/ratio of days where the weather was correctly predicted.
  2. The probability of correctly predicting a future date's weather based on a test dataset.

2. Data Preprocessing

Identifying anomalies in datasets before applying ML algorithms.

👨‍🏫 Teacher's Insight

This is an easy 5 marks. You will be given a small table of raw data. Your job is to act like a data analyst and spot 5 errors. Look for: Impossible values (outliers), typos, inconsistent formatting (e.g., adding units to some rows but not others), and missing data.

3. Regression & Tuning

Linear models, Gradient Descent, and bias-variance tradeoff.

👨‍🏫 Teacher's Insight

Two major mathematical concepts here. First: The Normal Equation dimensions. Remember, you must add an intercept feature (all ones). So if you have n features, your actual feature matrix has (n+1) columns.

Second: Gradient Descent. If your cost function J(θ) is increasing instead of decreasing, your steps are too big! You need to reduce the learning rate (α). Let's visualize this.

Gradient Descent Behavior

Notice how a learning rate that is too high causes the cost to diverge upward.

Model Complexity (Overfitting)

As polynomial degree increases, training error drops, but validation error spikes (overfitting).

📝 Predicted Questions

Q1: Suppose you have m=28 training examples with n=4 features (excluding the intercept). For the closed form solution θ = (XTX)-1XTy, what are the dimensions of θ, X, and y?

Q2: You run gradient descent for 15 iterations. You find J(θ) increases over time. What conclusion do you derive? Should you increase or decrease learning rate α?

✅ Solution Walkthrough

A1: Matrix Dimensions

We have m = 28 examples. Features n = 4. We must add the intercept term, making total features = 5.

  • X is a matrix of size m × (n+1) → 28 × 5
  • y is a vector of target values → 28 × 1
  • θ is the vector of weights for each feature → 5 × 1

A2: Gradient Descent Troubleshooting

Conclusion: The learning rate α is too high. The algorithm is taking steps that are too large, overshooting the minimum of the cost function, causing divergence.

Action: The learning rate α must be decreased.

4. Evaluation Metrics

Beyond Accuracy: Precision, Recall, and F-Score.

👨‍🏫 Teacher's Insight

When dealing with classification, especially imbalanced datasets, Accuracy can be misleading. You MUST know how to build a confusion matrix and calculate Precision, Recall, and F1-score. Use the interactive calculator below to practice. Notice how increasing False Positives destroys Precision, and increasing False Negatives destroys Recall.

📝 Predicted Question

A model predicts 50 instances. It correctly identified 30 positive cases and missed 10 actual positive cases. It incorrectly flagged 5 negative cases as positive. Calculate Precision, Recall, and F-score.

✅ Solution Walkthrough

First, extract the values:

  • Correctly identified positives = TP = 30
  • Missed actual positives = FN = 10
  • Incorrectly flagged negatives = FP = 5

Precision = TP / (TP + FP) = 30 / (30 + 5) = 30 / 35 = 0.857

Recall = TP / (TP + FN) = 30 / (30 + 10) = 30 / 40 = 0.75

F-Score = 2 × (Precision × Recall) / (Precision + Recall)
= 2 × (0.857 × 0.75) / (0.857 + 0.75)
= 1.2855 / 1.607 = 0.80

5. Decision Trees

Calculating Entropy and Information Gain for splits.

👨‍🏫 Teacher's Insight

This is often the most calculation-heavy part. You must understand that Entropy measures impurity. A perfectly mixed node (uniform distribution) has max entropy. A pure node has 0 entropy. We split nodes based on the feature that provides the highest Information Gain (i.e., reduces entropy the most). Formula: H = - ∑ p * log2(p).

📝 Predicted Question

A parent node has 20 samples: 12 belonging to Class 1, and 8 belonging to Class 2.
Upon splitting on attribute B, two child nodes are created:

  • Left child node: {9 Class1, 1 Class2}
  • Right child node: {3 Class1, 7 Class2}

Tasks:
a) Compute the Entropy of the parent node.
b) Compute the Information Gain of the split.
(Assume log2(0.6) ≈ -0.737, log2(0.4) ≈ -1.322)

✅ Solution Walkthrough

a) Entropy of Parent Node

Total = 20. p1 = 12/20 = 0.6. p2 = 8/20 = 0.4.
H(Parent) = - (0.6 * log2(0.6) + 0.4 * log2(0.4))
= - (0.6 * -0.737 + 0.4 * -1.322)
= - (-0.442 - 0.529) = 0.971 bits

b) Information Gain

First, calculate entropy of children.

Left Child (Total 10): p1=0.9, p2=0.1
H(Left) = - (0.9 * log20.9 + 0.1 * log20.1) ≈ 0.469

Right Child (Total 10): p1=0.3, p2=0.7
H(Right) = - (0.3 * log20.3 + 0.7 * log20.7) ≈ 0.881

Next, calculate weighted average entropy of children:

Weighted H = (10/20) * H(Left) + (10/20) * H(Right)
= 0.5 * 0.469 + 0.5 * 0.881 = 0.2345 + 0.4405 = 0.675

Finally, Information Gain = H(Parent) - Weighted H:

IG = 0.971 - 0.675 = 0.296 bits
